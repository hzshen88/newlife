## 0. 起草时已经看过的量

| 已看过 | 值 | 来源 |
|---|---|---|
| `qwen3.5:4b` 在 4 个扫描点上的**单次**输出 | `[-10.0, -1.5, -1.2, -1.25]` | 2026-09-06 实跑 |
| `qwen3.5:9b` 同上 | `[-1.0, -1.0, -12.5, -12.5]` | 同上 |
| `temperature=0` 连跑三次 | 逐字节相同（len=504） | 同上 |
| `temperature=0.7` 与之不同 | 是 | 同上 |
| run 上可用模型 | `qwen3.5:4b` · `qwen3.5:9b` · `qwen3:8b` · `gemma4` | `/api/tags` |
| **本检验在合成同分布数据上的一致率** | **0.925（n=16）· 0.875（n=32）**，各 40 次试验 | 冻结前实测 |

**最后一行是事前已知的判据缺陷，必须在这里说明。** 用冻结的参数（95%、Bonferroni 校正、
2000 次重采样）在**明确同分布**的合成数据上测，仍有约 **10%** 的概率判为「不同」——
理论上 Bonferroni 应给出 5%，实测更高，因为百分位 bootstrap 在小样本下覆盖不足。
两个 n 的差异落在 40 次试验的噪声内（比例标准误约 0.05），不构成 n 越大越差的证据。

**后果**：**S4 失败不能直接读成「判据太紧」**——大约每十次有一次是运气。产物必须连带
报告这个事前测得的率，供读者自行折算。这不是在为 H0 预留台阶：率是**冻结之前**测的、
写在这里，事后无法调整。

**以上全是单次观测，没有一个是分布。** 单次差异大**不蕴含**分布可分——方差可能同样大，
而那正是 S5 要判的东西。**未做过任何重复采样。**

## 1. 假设

- **H1**：同一个冻结的等价检验，能同时满足两端——同模型两批判为**等价**（S4），
  跨模型判为**不等价**（S5），且收敛在 `N_max` 内达到（S6）。
- **H0**：任一不成立。**H0 必须指名是哪一个**：S4 假 = 判据太紧（同模型也判不同）；
  S5 假 = 判据太松（分不开模型）；S6 假 = 这个世界需要的重复次数超出冻结的预算。

## 2. 判定单元（机械合取，runner 计算，**绝不手填**）

| Unit | What | Passes when | Piloted? |
|---|---|---|---|
| **S0** | **判定层**自我复现 | 给定同一 `samples.json`，两次独立运行的判定产物逐字节相同 | mechanical |
| **S1** | 环境未变 | 运行时已装的发行包恰是 `env.lock` 在冻结时记下的那些 | mechanical |
| **S2** | 检验在**合成样本**上正确 | ① 两组**明确分离**的样本对全部判为不等价；② 同分布样本的**一致率 ≥ 0.8**（20 组，每组 800 次重采样） | seen |
| **S3** | 每条判据都能变红 | 每个谓词在合成反例上返回 false，运行时计算 | mechanical |
| **S4** | **稳定性**：同模型两批判为等价 | 两个扫描点的 bootstrap CI **全部含 0** | **blind** |
| **S5** | **敏感性**：跨模型判为不等价 | **至少一个**扫描点的 CI 不含 0 | **blind** |
| **S6** | **收敛**：在 `N_max` 内达到 | 收敛判据成立，且产物记录实际 N | **blind** |

**verdict = S0 ∧ S1 ∧ S2 ∧ S3 ∧ S4 ∧ S5 ∧ S6.** 任一为假 → H0；**S0 为假 → INVALID**。

**S4 / S5 / S6 三格全盲**：pilot 只跑 S2 的合成样本，**不做任何真实采样**。
runner 在 `NEWLIFE_PILOT` 置位时不进入采样与判定路径，因此这三个键在 pilot 产物里不出现。
该条件**单向**：只由 `newlife pilot` 设置，正式 run 从不设置，故只能让 pilot 少算，
永远不能让判定少算。

**S4 与 S5 必须用同一个检验、同一个阈值。** 它们是松紧权衡的两端：调松则 S5 失败，
调紧则 S4 失败。**用两个不同的检验分别满足两端，是在回避本轮要问的问题。**

## 3. 冻结的实现约束

0. **S2 断言的是比率，不是单次结果。** 起草时它写成「一对同分布样本必须判为等价」，
   pilot 当场判假——那件事本来就有约一成概率不成立，**那是一枚硬币在假装成一个检查**。
   更值得记的是：这个错误形状在 `equivalence.py` 里已经被改掉，我却在「独立实现」的
   runner 里原样重犯了一次。**「写两遍」防的是实现错误，防不了设计错误**——两份实现
   出自同一个头脑，同一个想岔的地方会在两处同时出现。S2 的重采样次数取 800（低于生产
   的 2000）以控制预算，它测的是检验的统计性质，不是生产判定本身。
1. **等价检验**（唯一，两端共用）：对每个扫描点，两组样本均值差的 **bootstrap 百分位
   置信区间**，置信水平 **95%**，重采样 **2000** 次，RNG 种子 **20260906**。
   两个点**全部含 0** 判等价；**任一点不含 0** 判不等价。
   不用 t 检验：LLM 输出的分布形状未知，不做正态假设。
2. **收敛判据**：把当前这批 N 次**随机分成两半**（同一 RNG 种子派生），做**同一个**等价
   检验；判等价即收敛。未收敛则 N 翻倍。
3. **预算冻结**：`N_max = 32` · 扫描点 = **2** 个（吸附能 `-1.0` 与 `-4.0` eV）·
   `temperature = 0.7` · `think = false` · 模型 A = `qwen3.5:4b`、模型 B = `qwen3.5:9b`。
   **上限内未收敛必须如实记 S6 为假**，不取当前值充数。
4. **采样与判定分离**：采样把原始输出落盘 `samples.json`；判定只读该文件。
   **采样失败（网络、空响应）一律硬失败**，不许静默取部分样本——空响应的哈希会伪装成
   「两次一致」，本轮起草当日就实测撞到过一次。
5. **S0 作用在判定层**：内层复现运行读同一份 `samples.json`，不重新采样。
6. verdict runner **独立实现**检验与收敛判据，不得 import 或复用
   `newlife.stochastic.equivalence` 的代码路径。

## 4. 结果作废条件（与判据分开）

- 采样过程中远端服务不可达或返回空，导致样本数不足冻结的 N → `INVALID`，不记 H0。
  **服务不可用不是科学失败。**
- 检验的阈值、重采样次数或种子在冻结之后被修改 → `INVALID`。
- S4 与 S5 使用了不同的检验或不同的阈值（违反约束 1）→ `INVALID`。
- 判定层读取了 `samples.json` 之外的数据源 → `INVALID`。
- verdict runner 复用了 `equivalence` 模块的实现（违反约束 6）→ `INVALID`。

## 5. 事前声明：结论的边界

- 结论只覆盖**本项目这一个世界**——run 上 ollama 的两个 qwen3.5 模型、这一个提示、
  这两个扫描点。**不是**关于「一切随机模拟」或「一切 LLM」的断言。
- **不主张** bootstrap CI 是最优检验。它是一个**能被冻结、且能同时受两端拉扯**的检验，
  这就是本轮需要的全部。换一个检验可能得到不同的 H0/H1，这一点事前写明。
- **S0 的证明力在本轮被降低**（见 `@reproduction_class` 锚）。任何引用本轮 S0 的地方
  都必须连带引用那个限定。
- **不做** `seeded` 类的种子稳健性判据；**不改** `deterministic` 世界的任何行为；
  22 份既有产物逐字节不变。
- **S4 的判定力被上面那个 10% 的假警报率限制。** 单次 S4 失败的证据强度有限；
  要把它读成「判据确实太紧」，需要重复整轮实验，而那超出本轮预算。**本轮如实报告单次结果
  与事前率，不做超出证据的推断。**
- 参数（95%、2000 次重采样、Bonferroni）按**学科惯例与标准校正**选定，**不是**试出来的：
  冻结时尚未看过任何真实采样，无从调参去迎合结果。提高置信水平会降低假警报率但同时放松
  S5——那正是本轮要测的权衡，事前不许朝任一端偏。
- H1 成立也**不意味**这套机制对更慢或更贵的世界可用：`N_max=32` 是在单次调用约 2 秒的
  前提下选的，一次调用若要 2 分钟，同样的判据形状不改，但预算论证要重做。
