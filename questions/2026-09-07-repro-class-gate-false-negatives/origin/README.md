# origin/ — where this question came from

Questions do not appear from nowhere. Put the record of the exploration that produced
this one here, whatever tool it happened in:

- an exloop exploration: run its `handoff --to <this folder>` — it writes `events.jsonl`,
  `map.md` and a `goal-draft.md` shaped like `../goal.md` with §1 / §3 / §4 pre-filled
  (where the question came from, what was abandoned, what is still open); the six
  anchors stay TODO for the `newlife-goal` skill;
- a chat transcript, a notebook, a page of notes: copy it in as it is.

Two rules, both about the preregistration that follows:

1. **Everything in this folder counts as *seen*.** A number you looked at here cannot be
   a blind unit in `../prereg.md` §2, however it was obtained.
2. **Nothing here is evidence.** `newlife audit` does not read this folder, and neither
   does the verdict. It answers "why this question" — the one thing none of the first
   four real questions recorded.

Exploratory runs of the runner itself go next door: `newlife pilot` writes them to
`../pilot/<stamp>/` and records each run in `../pilot/ledger.jsonl`, which the freeze
reads.
