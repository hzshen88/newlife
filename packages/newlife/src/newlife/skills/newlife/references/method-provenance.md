# Method provenance

The unified workflow was informed by K-Dense's Science-Superpowers repository at commit
`ccc1b2d41a389b2d6dadf1945603f81d66c5e85e`, plugin version `0.1.0`, licensed MIT.

NewLife retains or adapts these method families in its own state model:

- research framing and source grounding;
- confirmatory/exploratory separation and preregistration;
- feasibility measurement before an expensive formal design;
- reproducible setup, anomaly diagnosis and evidence verification;
- skeptical review, response to criticism and reproducible reporting.

The consolidation removes the upstream package's universal invocation rule, fixed stage
chain, mandatory delegation, repeated informational pauses and generic branch-disposition
menu. Those are workflow-control decisions, not scientific safeguards.

The vendored `newlife/scaffold/prereg.sh` began from the Science-Superpowers
`preregistering-analysis/prereg.sh` and has since diverged for NewLife's question layout,
gates and exit-code contract. Its MIT notice is retained in the package's
`THIRD_PARTY_NOTICES.md`. New method text in the NewLife skills is independently written;
this file records conceptual provenance rather than asserting independent invention.
