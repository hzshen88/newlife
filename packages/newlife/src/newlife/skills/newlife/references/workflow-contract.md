# Unified workflow contract

NewLife owns formal question state. exloop owns optional pre-formal exploration state. Idea
Lab and method references are reasoning operations inside their caller, never new stages.

## Route and resume

1. Honor a direct bounded request. Do not start exploration merely because the subject is
   scientific.
2. Read existing session decisions, `newlife status` and question files before asking. Resume
   the current stage; do not replay framing.
3. Protect confirmatory outcomes before they are exposed. Anything already seen remains
   exploratory for that registration.
4. A source or method check returns evidence and limitations to its caller. It does not
   create a question or advance a stage.
5. Ask only for a consequential decision that cannot be recovered from context. Pause the
   dependent branch and continue independent authorized work.

## Person-owned decisions

- formalize an exploratory boundary;
- enter/exit feasibility mode and set its compute/abandonment boundary;
- freeze the named question/version;
- commit the named result set;
- change scientific direction or create a new registration after a frozen defect;
- merge, publish, send externally or destroy work when not already authorized.

Authorization persists only for the same object, version, scope and action. Silence is not
authorization. Routine inspection, drafting, validation, status reports and reversible
isolation are not additional gates when they are part of the authorized task.

## Evidence and completion

Reuse verification while code, inputs, environment and configuration remain unchanged.
Recheck the affected evidence after a relevant change. Do not rerun an unchanged pipeline
solely to repeat the same supported statement.

Report execution, reproduction, verdict/audit, report/archive, result commit and external
publication as separate states. Deliver completed artifacts before asking for the remaining
concrete action. A launched long run is not complete until exit/artifacts are checked or a
truthful recovery/monitoring handoff is established.

Never edit a frozen hypothesis, threshold, blind unit, decision rule or implementation
constraint in place. Diagnose it, preserve the record and create a new registration for a
new confirmatory attempt.
