## 1. 问题，与它为什么不是「找一个更好的判据」

第二十一个里程碑证明：**任何固定的收敛判据都会在某个世界上失效**。我设计的「两半判等价
即停」在方差大时反而更早喊停。用户据此把本轮的形状定了下来：

> 问题不一样，数据和算法不一样，需要重复多少次、用什么判据，也不可能都一样。
> **我们需要把方法论明确下来，而不是给一个明确的规则。因为规则给不出来。**

所以产出不是判据，是**一组冻结前必答的问题**加上「答不上来就冻不了」的强制。
这与 newlife 一贯的做法一致：它从不告诉你判据是什么，它强制你事先讲明白。

## 3. H0 的唯一来源是预算，不是方法论失灵

方法论对两个世界给出了实质不同的答案，**并且是数据决定的**：

| | 尾比 `sd/(1.4826·MAD)` | → 位置统计量 | → N |
|---|---|---|---|
| 世界 A（远端 LLM） | **3.77**（重） | `trimmed` | **判不了**（64 次调用内达不到 0.8 功效） |
| 世界 B（Moran 溯祖） | **1.17**（轻） | `mean` | **16** |

**S6 做到了第二十一个里程碑做不到的事**——同一个阈值同时满足两端：

| 世界 B，n=16，mean | 置信区间 | 含 0 |
|---|---|---|
| 稳定性（同 θ 两批） | `[-1.312, 0.750]` | 是 ✓ |
| 敏感性（θ 1→2） | `[-5.500, -2.312]` | 否 ✓ |

敏感性区间中心约 −3.9，与溯祖理论（θ 翻倍使 `E[segsites]` 增加约 2.59）方向一致、量级合理。

**S5 假的原因是世界 A 在 64 次调用的预算内判不了**，方法论如实输出了这一点。
**这是 M5 设计出来要的输出**，它顺带给出一个具体的资源需求：要分辨
`qwen3.5:4b` 与 `9b` 在这个提示上一个数量级的差异，64 次调用不够。

**H0 在这里比 H1 更有说服力**：若 S5 也通过，方法论会显得万能；现在它划出了一条实测的
边界——**重尾 ＋ 昂贵采样 ＝ 这个预算下判不了**。

## 4. S7：方法论不是伪装成方法的常量

两个变异系数差四倍的世界，若填出同一个答案，方法论就没在起作用而使用者无从察觉。
实际结果：**统计量不同（`trimmed` vs `mean`）、N 也不同（`None` vs `16`）**，两项都由
数据决定，不由人挑。

## 6. 如实记录

- **约束 3 起草时自相矛盾，冻结前改正并留档**。原文写「超上限记为『预算内判不了』
  **而非失败**」——那是错的：S5 断言的是「判据有判定力」，判不了就是没建立，
  **合取不该因为原因体面就放行**。「方法论正确地输出了『判不了』」与「本轮建立了判定力」
  是两件事。
- **判据设计的格式在自我评审后整个换掉**。第一版是单行 HTML 锚，三处会崩：多观测量装不下、
  锚体遇到第一个 `>` 就静默消失（当日刚在 `temperature>0` 上踩过）、理由无处展开。
  改为 `judgement-design.json`，以 `--data` 钉哈希——**它和判据一样不可事后修改**。
- **自我评审找出六条，修四条**：判定形式未声明（现在点名列出不支持的形式，
  **包括第二十一个里程碑自己的趋势问题**）· iid 假设无出口（AR(1) φ=0.85 实测
  0.74 对 0.80）· pilot 充分性循环（<30/点须书面说明）· 重尾自报改为交叉核对。
  余下两条（`derivation.method` 单值、`points` 语义）按「三个 provider 才抽象」的纪律
  留作已知边界。
- **英文守卫抓住一处疏忽**：随包发布的模块里混入了中文 docstring，`test_public_english`
  报出。守卫只查 docstring，fixture 里的中文字符串是我主动清的——它们同样会随 wheel 发出去。
- **`independence` 与 `pilot_adequacy` 本轮只检查「是否声明」，取值正确性未被检验**，
  这一条事前写在注册 §5，避免 H1/H0 被读成「修正因子也验证过了」。

## 7. 产品产出（goal 的 C3）

`newlife-prereg` 规则七补上了「N 从哪来」：六个必答项、**顺序是形状→统计量→N**、
自举功效分析而非解析公式、「此预算下判不了」是正确答案、以及**明确的适用边界**
——本推导只覆盖两组位置比较，趋势、多组、斜率、比例都不在内。

配套的 `newlife.gates.judgement_design` 检查两件事：六项是否齐全带理由，以及
**声明的 N 能否从它自己写下的前提重推出来**。它从不评判效应量选得对不对——
那需要一个比提问者更懂这个问题的裁判，不存在。
