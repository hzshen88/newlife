## 1. 问题

结果每次都不同的世界，在 newlife 里只有两条死路：假装它是确定的（固定种子，S0 绿得没有
意义——第二十个里程碑实测过换模型而五门加审计全绿），或者拿不到任何结论
（`final = verdict if s0 else "INVALID"`）。规则七写了规格，本轮建造。

三个设计决定：**采样层与判定层分离**（S0 改判「给定同一份采样数据，判定可复现」）·
**同一把尺两个方向**（同模型须判等价、跨模型须判不等价）· **收敛不拍 N**（把当前这批
随机分两半，用同一把尺比，判等价即停）。

## 3. H0 要拆开看：失败的不是「分不开」，是样本量停在了 8

对手方押的是「4b 与 9b 的分布可能重叠到检不出差异」。**结果比这更具体，也更糟**：

| 可从产物复核的数 | 值 |
|---|---|
| `A2/-4.0` 的样本 | `[-10, -11.6, -10, -1.3, -32, **-400**, -0.4, -4]` |
| 该点标准差 | **138.28** |
| 该点 S4 的 CI 宽度 | **159.4** |
| 两个模型的均值差 | 约 **2–3** |

**效应量约是区间宽度的 2%。** 在这个方差下，任何两组 8 样本都会被判为等价——
S5 在数据到手之前就不可能通过。**这不是「两个模型分不开」的证据，是「判据在这个方差下
没有判定力」的证据。**

## 4. 收敛判据的方向是反的——本轮最有价值的发现

S6 报 `n=8` 收敛，而上限是 32。原因是判据的结构：

> **方差越大 → CI 越宽 → 两半越容易判等价 → 越早判「收敛」。**

**我设计的收敛判据，在最需要更多样本的时候最早喊停。** 它把「区间宽到什么都含 0」
误读成了「样本已经稳定」。

这个缺陷**只有在 S5 失败时才会暴露**：若 S5 侥幸通过，n=8 就成了「高效」的证据，
而不是判定力为零的证据。**H0 在这里买到的东西比 H1 多。**

**下一轮的规格由此确定**：收敛判据必须与**效应量**挂钩——例如要求 CI 宽度相对于待检测
的差异足够小——而不是只问「两半是否等价」。这条规格来自本轮的失败，不是来自想象。

## 6. 如实记录

- **写两遍防不了设计错误。** 「一对同分布样本必须判为等价」这个错误形状，在
  `equivalence.py` 的 selftest 里被抓住并改掉之后，**又在刻意独立实现的 runner 里被原样
  重犯**，由 pilot 判假拦下。约束 6 要求两份实现不共用代码路径，它防的是**实现**错误
  ——一个人写错一处，另一处不会错在同一个地方；但两份实现出自同一个头脑，
  **同一个想岔的地方会在两处同时出现**。已写进 prereg 约束 0 与两处代码注释。
- **多重比较在第一次 selftest 就被抓住**：两点各 95% 的合取只有约 90%，同分布数据一成
  概率判不同。已加 Bonferroni。**但校正后实测假警报率仍约 10%**（0.875–0.925，40 次
  试验），高于理论的 5%——百分位 bootstrap 在小样本下覆盖不足。该数在**冻结前**测得并
  写入 §0，因此 S4 为真这件事，其证据强度也应按此折算。
- **S0 的证明力在本轮被降级**，已在 `@reproduction_class` 锚中写明：它只证明「判定不引入
  新的不确定性」，不再证明「世界可复现」。任何引用本轮 S0 的地方都须连带引用该限定。
- **规模估计偏低 39%**：估 390、实际 541（`equivalence` 220 ＋ `__init__` 10 ＋ runner 311）。
  与上一轮同因——**「同一逻辑按纪律写两遍」仍未被完整计入**，尽管上一轮刚记过一次。
  连续两轮同一处漏算，说明它不该靠记忆：**成分清单里应当有「独立实现的第二份」这一固定项**。
