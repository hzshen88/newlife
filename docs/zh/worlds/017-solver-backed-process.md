## 4. H1 之下必须连报的三件事

### 4.1 逐字节复现在这里买到的是什么

**FBA 的最优解通常不唯一**——优化问题多半是退化的，不同代谢通路能给出同一个目标值
（生长速率）；FVA 这门方法存在，正是为了刻画这个范围。文献还提到单纯形类求解器在
连续解一串 LP 时默认 warm-start，而 dFBA 正是一串 LP。

> **逐字节复现在这里买到的是「同一个求解器的同一个选择」，不是「同一个科学答案」。**
> 换求解器、换 GLPK 版本，这条轨迹**没有理由**仍然逐字节相同，**本轮没测**。

这就是 X7（记录求解器身份）被列进**合取**而不是写成附注的原因：
不记录它，等于把前者冒充成后者。

### 4.2 GLPK 是第三条非 Python 依赖，而它是被顺带带进来的

`dep_declaration.py` 里那份「预注册 §2.1 的穷举，不得增删」**没有被改动**——
它是对**当时那份代码**的穷举。GLPK 是第十六个里程碑装 `spatio-flux` 时
（→ cobra → optlang → swiglpk）带进来的，**没有任何东西提醒**。

> **穷举有有效期。** 依赖面会被后来的改动扩大，而扩大它的人不一定知道有那样一份穷举。

新增 `DISCOVERED_SINCE` 单独记录，并如实写明**第十三个里程碑的 PATH 屏蔽实验
够不着这一类**：`shutil.which` 只对可执行文件有效，GLPK 是被 `swiglpk` 链进 Python
扩展的共享库。要真测得动 dyld/ld.so 搜索路径——**本轮没做**。

### 4.3 端口的粒度限制了声明的粒度

按 key 接线时，一条 `StateDelta` 只有**一个**路径，所以 `substrates` 的写入只能
声明在父路径 `("fields",)` 上——**比第三方实际写的位置粗**（父路径也覆盖 `biomass`）。

**不是实现偷懒，是接法本身的上限。** 记在声明文件的开头，不藏。
